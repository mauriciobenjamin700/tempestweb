# `tempestweb.components`

Campos, formulários e botões Material 3 prontos, incluindo os campos brasileiros (CPF, CNPJ, telefone, endereço) e os validadores que os acompanham. São componentes de **conteúdo**; a moldura da tela vem de `tempestweb.presets` ou é montada por você.

Guia com exemplos: [Componentes prontos](../tutorial/components.md).

::: tempestweb.components
