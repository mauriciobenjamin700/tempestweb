# `tempestweb.export`

CSV and XLSX generation in pure Python, for [`native.file.save`](../advanced/native-reference.md) to deliver. Modes A and B (Mode C refuses the import at build time). Installs nothing — `zipfile` and `xml.etree` from the standard library are enough for XLSX.

Guide with examples: [Export CSV and XLSX](../advanced/export.md).

::: tempestweb.export
