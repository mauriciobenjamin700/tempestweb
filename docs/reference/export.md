# `tempestweb.export`

Geração de CSV e XLSX em Python puro, para o [`native.file.save`](../advanced/native-reference.md) entregar. Roda nos três modos e não instala nada — `zipfile` e `xml.etree` da stdlib bastam para o XLSX.

Guia com exemplos: [Exportar CSV e XLSX](../advanced/export.md).

::: tempestweb.export
