# `tempestweb.native`

As Web APIs do browser como awaitables Python tipados — geolocalização, clipboard, câmera, HTTP, armazenamento, sensores, WebPush. A mesma chamada `await native.<capacidade>()` funciona nos Modos A e B; o que muda é só quem executa do outro lado da ponte.

Guia com exemplos: [Capacidades nativas](../advanced/capabilities.md) · [Referência de capacidades](../advanced/native-reference.md) · [Canal de eventos nativo](../advanced/native-events.md).
