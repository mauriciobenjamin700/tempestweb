# `tempestweb.presets`

Telas prontas para painel administrativo, montadas a partir de registros tipados (`NavItem`, `Kpi`, `Section`, `TableColumn`, `FormField`) em vez de widgets de layout. Você importa daqui quando a tela é um arquétipo — shell, dashboard, listagem, formulário, login.

Guia com exemplos: [Telas prontas (presets)](../tutorial/presets.md) · [Console administrativo](../examples/admin-console.md).

::: tempestweb.presets
