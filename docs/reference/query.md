# `tempestweb.query`

O lado da **leitura** do dado remoto: cache com chave hierárquica, invalidação por prefixo, single-flight, paginação nas duas formas e mutação otimista com rollback exato. Modos A e B (o Modo C recusa o import no build). Não substitui o [`native.sync`](../advanced/offline-sync.md), que continua sendo o caminho para reconciliar coleção grande.

Tutorial com exemplos: [Lendo dados remotos](../tutorial/query.md).

::: tempestweb.query
