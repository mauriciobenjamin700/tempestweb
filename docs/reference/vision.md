# `tempestweb.vision`

Classificação, detecção e segmentação sobre ONNX, com a mesma API do `ort-vision-sdk`. Exige o extra `[vision]`. Carregar o modelo e rodar inferência são operações longas — tire-as do handler com `tempestweb.runtime.spawn`.

Guia com exemplos: [Visão computacional (ONNX)](../advanced/vision.md).
